# IMDb Movies SQL Analysis

## Project Overview

This project analyzes an IMDb movies database using SQL to answer analytical questions related to movies, directors, popularity, revenue, ratings, and movie performance.

The project was completed as part of the DataMites Data Analytics program using MySQL.

## Project Type

DataMites Capstone Project

## Tools Used

- MySQL Workbench

## Analysis Performed

The project involved writing SQL queries to:

- Retrieve and explore movie and director data
- Count movies and directors
- Filter data using specific conditions
- Analyze movie popularity and revenue
- Identify highly rated movies
- Analyze directors and their movie performance
- Join movie and director tables
- Use aggregation, sorting, grouping, and ranking techniques
